What this project is doing

Simple, secure, and demo-friendly

Connect

Establish a secure path

The project shows how SAS can connect to Databricks through supported patterns without exposing secrets in the browser.

Load

Land data in CAS

Once connected, the pattern loads the data into a CAS library so SAS analytic workflows can work on it efficiently.

Prepare

Validate before modeling

Before model development, this repo points toward profile checks, duplicate review, and missingness analysis.

Why it matters

  • Databricks is often the source of truth for operational and analytical data.
  • SAS Viya is often the platform used for analytics, reporting, scoring, and forecasting.
  • The design challenge is not merely connectivity, but a secure and understandable way to move data between them.
  • This demo focuses on that handoff and on making the architecture visible to the user.
This repository is a concept project for a Databricks-to-Viya data flow. It is designed to make the architecture clear and to provide a clean starting point for a real implementation.
